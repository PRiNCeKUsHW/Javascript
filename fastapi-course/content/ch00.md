::: flow Your learning path
> Here's the map of the course.
- 🌱 Basics (Levels 1–4)
> Levels one to four cover the basics: routes, parameters, Pydantic models and responses.
- 🧩 Core skills (5–7)
> Then core skills: dependency injection, databases, and structuring bigger apps.
- 🔐 Security & async (8–9)
> Then security, authentication and background work.
- 🧪 Testing & advanced (10–11)
> Then testing, and advanced features like WebSockets and file uploads.
- 🚀 Production (12–13)
> And finally production deployment, plus three portfolio projects.
:::

::: concept How every level works
- 📘 **Learn**: simple explanations, real examples, then code

- ⏱️ **Challenge Time**: 5 questions, pause and solve
> Then Challenge Time: five questions with a timer. Pause the video and solve each one yourself.
- 🛠️ **Project Time**: build a mini project, then see the solution
> Then Project Time, where you build a small real project and then watch the solution.
- 🎤 **Boss Round**: a mock interview with model answers
