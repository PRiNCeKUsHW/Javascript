::: title
- Build real APIs from scratch
- Practice challenges and a project every level
- Mock interviews from junior to senior
- Ship to production like a pro
> नमस्ते दोस्तों! FastAPI Zero to Production course में आपका स्वागत है।
> चाहे आप college student हों या working professional, ये course आपको शुरुआत से लेकर production level तक ले जाएगा, बिल्कुल आसान भाषा में।
:::

::: concept Why learn FastAPI now?
- Almost every app today talks to a backend **API**
> आज लगभग हर app, चाहे mobile हो या web, पीछे किसी API से बात करता है।
- Python + FastAPI is a top choice for APIs, ML and AI services
> Python और FastAPI APIs बनाने के लिए top choice है, खासकर machine learning और AI services के लिए।
- Companies hire for it: backend, full-stack and ML engineer roles
> इसलिए backend, full stack और ML engineer की jobs में FastAPI बहुत माँगा जाता है।
- Easy to start, powerful enough for production
> और सबसे अच्छी बात, ये सीखने में आसान है, लेकिन production के लिए पूरा powerful है।
:::

::: flow Your learning path
> चलिए course का map देखते हैं।
- Basics (Levels 1–4)
> पहले चार levels में basics, यानी routes, parameters, Pydantic और responses।
- Core skills (5–7)
> फिर core skills, dependency injection, database और बड़े projects का structure।
- Security & async (8–9)
> उसके बाद authentication, security और async background work।
- Testing & advanced (10–11)
> फिर testing और advanced features जैसे WebSockets और file uploads।
- Production (12–13)
> और आखिर में production deployment, और तीन portfolio projects।
:::

::: concept How every level works
- **Learn**: easy explanation with real-life examples, then code
> हर level में पहले Learn part होगा, जिसमें real life example से concept समझेंगे, फिर code देखेंगे।
- **Challenge Time**: 5 questions, pause and solve yourself
> फिर Challenge Time, पाँच सवाल। Timer आते ही video pause कीजिए और खुद solve कीजिए।
- **Project Time**: build a mini project, then see the solution
> फिर Project Time, जिसमें आप एक छोटा real project खुद बनाएँगे, और फिर मैं solution दिखाऊँगी।
- **Boss Round**: mock interview questions with model answers
> और आखिर में Boss Round, यानी mock interview, junior से senior level तक के सवाल और उनके model answers।
:::

::: concept What you need
- Basic Python: variables, functions, classes, lists and dicts
> इस course के लिए आपको बस basic Python आनी चाहिए, जैसे functions, classes, lists और dictionaries।
- Python 3.10 or newer, and VS Code or any editor
> Python का version three point ten या उससे नया हो, और कोई भी editor, जैसे VS Code।
- No web or API experience needed
> Web development या API का पहले से कोई experience ज़रूरी नहीं है।
- Code along: type every example yourself
> बस एक request है, हर example खुद type कीजिए। देखकर नहीं, करके सीखते हैं।
:::
