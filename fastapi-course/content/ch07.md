::: code app/repositories/tasks.py | The repository: only database queries
```python
class TaskRepository:
    def __init__(self, session: AsyncSession):
        self.session = session

    async def list(self, done: bool | None = None) -> list[Task]:
        stmt = select(Task).order_by(Task.id.desc())
        if done is not None:
            stmt = stmt.where(Task.done == done)
        return list(await self.session.scalars(stmt))

    async def exists_title(self, title: str) -> bool:
        stmt = select(Task.id).where(Task.title == title)
        return (await self.session.scalar(stmt)) is not None

    async def add(self, task: Task) -> Task:
        self.session.add(task)
        await self.session.flush()
        return task
```
@1-3 > The repository receives a session, and only talks to the database.
@5-9 > list builds the query with the optional filter.
@11-13 > exists title answers one yes or no question.
@15-18 > add stages the task, and flush sends it to the database so the id is assigned, but without committing yet.
:::

::: code app/services/tasks.py | The service: business rules and the commit
```python
class TaskService:
    def __init__(self, repo: TaskRepository, session: AsyncSession):
        self.repo = repo
        self.session = session

    async def create(self, data: TaskCreate) -> Task:
        if await self.repo.exists_title(data.title):
            raise TaskAlreadyExists(data.title)
        task = await self.repo.add(Task(**data.model_dump()))
        await self.session.commit()
        return task


def get_task_service(session: SessionDep) -> TaskService:
    return TaskService(TaskRepository(session), session)


TaskServiceDep = Annotated[TaskService, Depends(get_task_service)]
```
@6-8 > The service holds the rule: no two tasks with the same title. It raises a domain exception, with no HTTP in sight.
@9-11 > And the service decides when to commit. One clear place, which fixes the forgotten commit bug from last level.
@14-18 > A small dependency wires the layers together, and TaskServiceDep is what routers ask for.
@18 L> And the four oh nine comes from an exception handler, like in level four?
@18 > Exactly. Everything we've learned is now clicking together.

::: code app/main.py | lifespan and versioned routers
```python
@asynccontextmanager
async def lifespan(app: FastAPI):
    app.state.http = httpx.AsyncClient(timeout=10)
    yield
    await app.state.http.aclose()
    await engine.dispose()


settings = get_settings()
app = FastAPI(title=settings.app_name, lifespan=lifespan)
app.include_router(tasks.router, prefix="/api/v1")
app.include_router(users.router, prefix="/api/v1")
```
@1-3 > lifespan runs code at startup. Here we create one shared HTTP client for the whole app.
@4-6 > After yield comes shutdown: close the client and dispose of the database engine.
@4 L> Why not create the HTTP client inside each request?
@4 > Because creating clients is slow and wastes connections. Create once, reuse everywhere.
@9-10 > The app takes its name from settings, and the lifespan function.
@11-12 > Routers are included under slash api slash v one. A future version two can live next to it.
